# 광고 성과 대시보드

## 배포
1. GitHub에서 새 공개 또는 비공개 저장소를 만듭니다.
2. `index.html`, `data.js` 두 파일을 저장소 최상위에 업로드합니다.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. 배포 주소는 일반적으로 `https://사용자명.github.io/저장소명/`입니다.

## 데이터 기준
- 도담 및 지빌리언즈를 구분하고, 네이버 SA와 쿠팡을 별도 조회합니다.
- 네이버: `광고raw` 시트의 캠페인별·유형별 집계. 원본에 날짜 열이 없어 월별 추이 불가.
- 쿠팡: `(직접입력) 주차별raw` 시트의 2026-09-01~2026-11-15 자료, **1일 전환** 기준.
- CTR=클릭/노출, CVR=전환/클릭, CPC=광고비/클릭, ROAS=전환매출/광고비×100.
- 키워드 데이터는 제외했습니다. 네이버 AD부스트·GFA 별도 피벗은 SA raw와 합산하지 않았습니다.
- 쿠팡 월 선택 시 KPI와 일별 그래프만 월 필터가 적용되며 캠페인/유형 표는 전체 기간입니다.

## 주의
GitHub Pages는 게시된 정적 데이터를 방문자가 볼 수 있습니다. 외부 공유 전에 데이터 공개 범위를 확인하세요. 원본 엑셀은 업로드할 필요 없습니다.
